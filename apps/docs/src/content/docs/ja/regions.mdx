title: リージョンの選択
---

Cogbox は現在、以下のリージョンで利用可能です。

- 米国（US）
- 欧州（EU）

Cogbox の[設定](/docs/ja/configuration)手順でリージョンを選択できます。

```python
from cogbox import Cogbox, CogboxConfig

config = CogboxConfig(
    target="us"
)

cogbox = Cogbox(config)
```

```typescript
import { Cogbox } from '@cogbox/sdk';

const cogbox: Cogbox = new Cogbox({
    target: "eu"
});
```
