Cogbox の TypeScript SDK は、Cogbox のサンドボックスをプログラムから操作するための強力なインターフェースを提供します。

## インストール

npm を使用して Cogbox の TypeScript SDK をインストールします：

```bash
npm install @cogbox/sdk
```

または yarn を使用します：

```bash
yarn add @cogbox/sdk
```

## はじめに

Cogbox の TypeScript SDK を使い始めるための簡単な例を紹介します:

```typescript
import { Cogbox } from '@cogbox/sdk'

async function main() {
  // SDK を初期化（デフォルトで環境変数を使用）
  const cogbox = new Cogbox()

  // 新しいサンドボックスを作成
  const sandbox = await cogbox.create({
    language: 'typescript',
    envVars: { NODE_ENV: 'development' },
  })

  // コマンドを実行
  const response = await sandbox.process.executeCommand('echo "Hello, World!"')
  console.log(response.result)
}

main().catch(console.error)
```

## 設定

SDK は環境変数を使うか、コンストラクターにオプションを渡して設定できます:

```typescript
import { Cogbox } from '@cogbox/sdk';

// 環境変数を使用 (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
const cogbox = new Cogbox();

// 明示的な設定を指定
const cogbox = new Cogbox({
  apiKey: 'your-api-key',
  apiUrl: 'https://cogbox.pazity.com/api',
  target: 'us'
});
```
