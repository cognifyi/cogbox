## 環境変数を設定する

Cogbox で認証するには API キーが必要です。API キーは Cogbox プラットフォームから取得できます。

1. [Cogbox Dashboard](https://cogbox.pazity.com/dashboard/) にアクセスします。
2. API Keys を開きます。
3. **`Create Key`** ボタンをクリックします。
4. **`.env`** ファイルで **`COGBOX_API_KEY`** 環境変数を設定し、API キーを追加します。
5. **`.env`** ファイルで **`COGBOX_API_URL`** 環境変数を設定し、Cogbox の API URL を指定します。

## 構成オプション

Cogbox SDK では、Python と TypeScript で `CogboxConfig` クラスを使用して設定を行えます。`CogboxConfig` クラスは次のパラメータを受け取ります。

- `api_key`: Cogbox の APIキー
- `api_url`: Cogbox の API の URL
- `target`: サンドボックスを作成する Cogbox のターゲット（リージョン）

<Tabs syncKey="language">
<TabItem label="Python" icon="seti:python">
```python
from cogbox import CogboxConfig

config = CogboxConfig(
    api_key="your-api-key",
    api_url="your-api-url",
    target="us"
)

```
</TabItem>
<TabItem label="TypeScript" icon="seti:typescript">
```typescript
import { CogboxConfig } from '@cogbox/sdk';

const config: CogboxConfig = {
    apiKey: "your-api-key",          
    apiUrl: "your-api-url",     
    target: "us"                  
};
```

</TabItem>
</Tabs>

## 環境変数

Cogbox SDK は設定に環境変数を利用できます。SDK は次の環境変数を自動的に参照します：

| Variable              | Description                                | Optional |
| --------------------- | ------------------------------------------ | -------- |
| **`COGBOX_API_KEY`** | Cogbox の APIキー。                        |          |
| **`COGBOX_API_URL`** | Cogbox API の URL。                        | Yes      |
| **`COGBOX_TARGET`**  | サンドボックスを作成する Cogbox のターゲット（ターゲット（リージョン））。 | Yes      |

### 環境変数の設定

Cogbox SDK は環境変数から設定を読み込みます。以下の方法で設定できます。

- [**`.env`** ファイルを使用](#using-a-env-file)
- [シェル環境を使用](#using-shell-environment)

#### **`.env`** ファイルを使用

プロジェクトのルートディレクトリに `.env` ファイルを作成します：

```bash
COGBOX_API_KEY=your-api-key
COGBOX_API_URL=https://your-api-url
COGBOX_TARGET=us
```

- `COGBOX_API_KEY`: Cogbox の APIキー。
- `COGBOX_API_URL`: Cogbox API の URL。
- `COGBOX_TARGET`: サンドボックスを作成する Cogbox のターゲット（ターゲット（リージョン））。

#### シェル環境を使用

シェルで環境変数を設定します：

<Tabs syncKey="shell">
<TabItem label="Bash/Zsh" icon="seti:shell">
```bash
export COGBOX_API_KEY=your-api-key
export COGBOX_API_URL=https://your-api-url
```
</TabItem>
<TabItem label="Windows PowerShell" icon="seti:powershell">
```bash
$env:COGBOX_API_KEY="your-api-key"
$env:COGBOX_API_URL="https://your-api-url"
```
</TabItem>
</Tabs>

## 設定の優先順位

SDK は設定に対して次の優先順位（高い順）を適用します:

1. コード内で明示的に指定された設定
2. 環境変数
3. 設定ファイル
4. デフォルト値
