Cogbox SDK は Cogbox と対話するための公式の Python および TypeScript インターフェースを提供し、開発環境をプログラムから管理してコードを実行できます。

### クイックスタート

Cogbox のサンドボックスで最初のコードを実行しましょう。AI アシスタントとの開発を加速するために、[LLMs のコンテキストファイル](/docs/ja/getting-started#additional-examples)を活用してください。

#### 1. APIキーを取得する

- Cogbox の[ダッシュボード](https://cogbox.pazity.com/dashboard)に移動します。
- 新しい[APIキー](https://cogbox.pazity.com/dashboard/keys)を作成します。安全な場所に保存してください。再表示はされません。

#### 2. SDK をインストールする

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```bash
    pip install cogbox
    ```
  </TabItem>

  <TabItem label="TypeScript" icon="seti:typescript">
    ```bash
    npm install @cogbox/sdk
    ```
  </TabItem>
</Tabs>

#### 3. コードを書く

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    次の名前のファイルを作成します: `main.py`

    ```python
    from cogbox import Cogbox, CogboxConfig

    # 設定を定義

    config = CogboxConfig(api_key="your-api-key")

    # Cogbox クライアントを初期化

    cogbox = Cogbox(config)

    # サンドボックスのインスタンスを作成

    sandbox = cogbox.create()

    # サンドボックス内で安全にコードを実行

    response = sandbox.process.code_run('print("Hello World from code!")')
    if response.exit_code != 0:
      print(f"Error: {response.exit_code} {response.result}")
    else:
        print(response.result)

    # 後片付け

    sandbox.delete()

    ```
  </TabItem>

  <TabItem label="TypeScript" icon="seti:typescript">
    次の名前のファイルを作成します: `index.mts`

    ```typescript
    import { Cogbox } from '@cogbox/sdk';

    // Cogbox クライアントを初期化
    const cogbox = new Cogbox({ apiKey: 'your-api-key' });

    // サンドボックスのインスタンスを作成
    const sandbox = await cogbox.create({
      language: 'typescript',
    });

    // サンドボックス内で安全にコードを実行
    const response = await sandbox.process.codeRun('console.log("Hello World from code!")')
    console.log(response.result);

    // 後片付け
    await sandbox.delete()
    ```
  </TabItem>
</Tabs>

:::note
`your-api-key` は Cogbox ダッシュボードで取得した値に置き換えてください。
:::

#### 4. 実行する

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```bash
    python main.py
    ```
  </TabItem>

  <TabItem label="TypeScript" icon="seti:typescript">
    ```bash
    npx tsx index.mts
    ```
  </TabItem>
</Tabs>

#### ✅ 今やったこと

- Cogbox SDK をインストールしました。
- セキュアなサンドボックス環境を作成しました。
- そのサンドボックス内でコードをリモート実行しました。
- 出力をローカルで取得して表示しました。

これで、Cogbox を使ったセキュアで分離されたコード実行を開始できます。
