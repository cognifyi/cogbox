Cogbox の Python SDK は、Cogbox サンドボックスとプログラム的にやり取りするための堅牢なインターフェースを提供します。

## インストール

pip で Cogbox の Python SDK をインストールします:

```bash
pip install cogbox
```

または poetry を使用します:

```bash
poetry add cogbox
```

## はじめに

Cogbox の Python SDK を使い始めるためのシンプルな例を示します。

<Tabs syncKey="language">
  <TabItem label="Sync" icon="seti:python">
    ```python
    from cogbox import Cogbox

    def main():
        # SDK を初期化（既定で環境変数を使用）
        cogbox = Cogbox()

        # サンドボックスを新規作成
        sandbox = cogbox.create()

        # コマンドを実行
        response = sandbox.process.exec("echo 'Hello, World!'")
        print(response.result)

    if __name__ == "__main__":
        main()
    ```
  </TabItem>

  <TabItem label="Async" icon="seti:python">
    ```python
    import asyncio
    from cogbox import AsyncCogbox

    async def main():
        # SDK を初期化（既定で環境変数を使用）
        async with AsyncCogbox() as cogbox:
            # サンドボックスを新規作成
            sandbox = await cogbox.create()

            # コマンドを実行
            response = await sandbox.process.exec("echo 'Hello, World!'")
            print(response.result)

    if __name__ == "__main__":
        asyncio.run(main())
    ```
  </TabItem>
</Tabs>

## 構成

SDK は環境変数を使うか、コンストラクタにオプションを渡して設定できます:

<Tabs syncKey="language">
  <TabItem label="Sync" icon="seti:python">
    ```python
    from cogbox import Cogbox, CogboxConfig

    # 環境変数を使用 (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
    cogbox = Cogbox()

    # 明示的な設定を使用
    config = CogboxConfig(
        api_key="your-api-key",
        api_url="https://cogbox.pazity.com/api",
        target="us"
    )
    cogbox = Cogbox(config)
    ```
  </TabItem>

  <TabItem label="Async" icon="seti:python">
    ```python
    import asyncio
    from cogbox import AsyncCogbox, CogboxConfig

    async def main():
        try:
            # 環境変数を使用 (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
            cogbox = AsyncCogbox()
            # 非同期コードをここに記述
            pass
        finally:
            await cogbox.close()

        # 明示的な設定を使用
        config = CogboxConfig(
            api_key="your-api-key",
            api_url="https://cogbox.pazity.com/api",
            target="us"
        )
        async with AsyncCogbox(config) as cogbox:
            # ここにコードを記述
            pass

    if __name__ == "__main__":
        asyncio.run(main())
    ```
  </TabItem>
</Tabs>
