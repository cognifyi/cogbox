The Cogbox Go SDK provides a powerful interface for programmatically interacting with Cogbox Sandboxes. It requires Go 1.25 or later.

## Installation

Install the Cogbox Go SDK using go get:

```bash
go get github.com/cognifyi/cogbox/libs/sdk-go
```

## Getting Started

### Create a Sandbox

Create a Cogbox Sandbox to run your code securely in an isolated environment. The following snippet is an example "Hello World" program that runs securely inside a Cogbox Sandbox.

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/cognifyi/cogbox/libs/sdk-go/pkg/cogbox"
)

func main() {
	// Initialize the SDK (uses environment variables by default)
	client, err := cogbox.NewClient()
	if err != nil {
		log.Fatal(err)
	}

	// Create a new sandbox
	sandbox, err := client.Create(context.Background(), nil)
	if err != nil {
		log.Fatal(err)
	}

	// Execute a command
	response, err := sandbox.Process.ExecuteCommand(context.Background(), "echo 'Hello, World!'")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(response.Result)
}
```

## Configuration

The Cogbox SDK can be configured using environment variables or by passing options to the constructor:

```go
package main

import (
	"github.com/cognifyi/cogbox/libs/sdk-go/pkg/cogbox"
	"github.com/cognifyi/cogbox/libs/sdk-go/pkg/types"
)

func main() {
	// Using environment variables (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
	client, _ := cogbox.NewClient()

	// Using explicit configuration
	config := &types.CogboxConfig{
		APIKey: "YOUR_API_KEY",
		APIUrl: "https://cogbox.pazity.com/api",
		Target: "us",
	}
	client, _ = cogbox.NewClientWithConfig(config)
}
```

For more information on configuring the Cogbox SDK, see [configuration](/docs/en/configuration).
