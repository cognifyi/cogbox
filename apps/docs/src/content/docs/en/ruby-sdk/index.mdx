The Cogbox Ruby SDK provides a robust interface for programmatically interacting with Cogbox Sandboxes.

## Installation

Install the Cogbox Ruby SDK using Bundler by adding it to your Gemfile:

```ruby
gem 'cogbox'
```

Then run:

```bash
bundle install
```

Or install it directly:

```bash
gem install cogbox
```

## Getting Started

Here's a simple example to help you get started with the Cogbox Ruby SDK:

```ruby
require 'cogbox'

# Initialize the SDK (uses environment variables by default)
cogbox = Cogbox::Cogbox.new

# Create a new sandbox
sandbox = cogbox.create

# Execute a command
response = sandbox.process.exec(command: "echo 'Hello, World!'")
puts response.result

# Clean up
cogbox.delete(sandbox)
```

## Configuration

The SDK can be configured using environment variables or by passing options to the constructor:

```ruby
require 'cogbox'

# Using environment variables (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
cogbox = Cogbox::Cogbox.new

# Using explicit configuration
config = Cogbox::Config.new(
  api_key: 'your-api-key',
  api_url: 'https://cogbox.pazity.com/api',
  target: 'us'
)
cogbox = Cogbox::Cogbox.new(config)
```

## Environment Variables

The SDK supports the following environment variables:

| Variable | Description |
|----------|-------------|
| `COGBOX_API_KEY` | API key for authentication |
| `COGBOX_API_URL` | URL of the Cogbox API (defaults to `https://cogbox.pazity.com/api`) |
| `COGBOX_TARGET` | Target location for Sandboxes |
| `COGBOX_JWT_TOKEN` | JWT token for authentication (alternative to API key) |
| `COGBOX_ORGANIZATION_ID` | Organization ID (required when using JWT token) |
