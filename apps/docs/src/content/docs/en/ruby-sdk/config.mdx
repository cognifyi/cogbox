## Config

Main class for a new Cogbox::Config object.

### Constructors

#### new Config()

```ruby
def initialize(api_key:, jwt_token:, api_url:, organization_id:, target:, otel_enabled:, _experimental:)

```

Initializes a new Cogbox::Config object.

**Parameters**:

- `api_key` _String, nil_ - Cogbox API key. Defaults to ENV['COGBOX_API_KEY'].
- `jwt_token` _String, nil_ - Cogbox JWT token. Defaults to ENV['COGBOX_JWT_TOKEN'].
- `api_url` _String, nil_ - Cogbox API URL. Defaults to ENV['COGBOX_API_URL'] or Cogbox::Config::API_URL.
- `organization_id` _String, nil_ - Cogbox organization ID. Defaults to ENV['COGBOX_ORGANIZATION_ID'].
- `target` _String, nil_ - Cogbox target. Defaults to ENV['COGBOX_TARGET'].
- `otel_enabled` _Boolean, nil_ - Enable OpenTelemetry tracing for SDK operations.
- `_experimental` _Hash, nil_ - Experimental configuration options.

**Returns**:

- `Config` - a new instance of Config

#### read_env()

```ruby
def read_env(name)

```

Reads a COGBOX_-prefixed environment variable using the same precedence
as the Config initializer: runtime ENV first, then .env.local, then .env.
Only names starting with COGBOX_ are accepted.

**Parameters**:

- `name` _String_ - The environment variable name. Must start with COGBOX_.

**Returns**:

- `String, nil` - The value of the environment variable, or nil if not set.

**Raises**:

- `ArgumentError` - If name does not start with COGBOX_.
