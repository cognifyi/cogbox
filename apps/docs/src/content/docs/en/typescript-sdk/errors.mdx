## CogboxAuthenticationError

Error thrown when authentication fails (HTTP 401).

**Properties**:

- `errorCode?` _string_ - Machine-readable error code if available
    - _Inherited from_: `CogboxError.errorCode`
- `headers?` _AxiosHeaders_ - Response headers if available
    - _Inherited from_: `CogboxError.headers`
- `statusCode?` _number_ - HTTP status code if available
    
    - _Inherited from_: `CogboxError.statusCode`




**Example:**

```ts
try {
  for await (const sandbox of cogbox.list()) {
    console.log(sandbox.id)
  }
} catch (error) {
  if (error instanceof CogboxAuthenticationError) {
    console.log(error.statusCode)
  }
}
```

**Extends:**

- `CogboxError`
