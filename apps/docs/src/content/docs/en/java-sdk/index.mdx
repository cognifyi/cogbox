The Cogbox Java SDK provides a robust interface for programmatically interacting with Cogbox Sandboxes. It targets Java 11+ and uses OkHttp and Jackson.

## Installation

### Gradle

Add the Cogbox SDK dependency to your `build.gradle.kts`:

```kotlin
dependencies {
    implementation("io.cogbox:sdk:x.y.z")
}
```

### Maven

Add the Cogbox SDK dependency to your `pom.xml`:

```xml
<dependency>
  <groupId>io.cogbox</groupId>
  <artifactId>sdk</artifactId>
  <version>x.y.z</version>
</dependency>
```

## Getting Started

### Create a Sandbox

Create a Cogbox Sandbox to run your code securely in an isolated environment. The following snippet is an example "Hello World" program that runs securely inside a Cogbox Sandbox.

```java
import io.cogbox.sdk.Cogbox;
import io.cogbox.sdk.Sandbox;
import io.cogbox.sdk.model.ExecuteResponse;

public class Main {
    public static void main(String[] args) {
        // Initialize the SDK (uses environment variables by default)
        try (Cogbox cogbox = new Cogbox()) {
            // Create a new sandbox
            Sandbox sandbox = cogbox.create();

            // Execute a command
            ExecuteResponse response = sandbox.getProcess().executeCommand("echo 'Hello, World!'");
            System.out.println(response.getResult());

            // Clean up
            sandbox.delete();
        }
    }
}
```

## Configuration

The Cogbox SDK can be configured using environment variables or by passing a configuration object:

```java
// Using environment variables (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
Cogbox cogbox = new Cogbox();
```

```java
// Using explicit configuration
CogboxConfig config = new CogboxConfig.Builder()
    .apiKey("YOUR_API_KEY")
    .apiUrl("YOUR_API_URL")
    .target("us")
    .build();
Cogbox cogbox = new Cogbox(config);
```

For more information on configuring the Cogbox SDK, see [configuration](/docs/en/configuration).
