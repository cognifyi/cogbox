The Cogbox Python SDK provides a robust interface for programmatically interacting with Cogbox Sandboxes.

## Installation

Install the Cogbox Python SDK using pip:

```bash
pip install cogbox
```

Or using poetry:

```bash
poetry add cogbox
```

## Getting Started

### Create a Sandbox

Create a Cogbox Sandbox to run your code securely in an isolated environment. The following snippet is an example "Hello World" program that runs securely inside a Cogbox Sandbox.

<Tabs>
  <TabItem label="Sync" icon="seti:python">
    ```python
    from cogbox import Cogbox

    def main():
        # Initialize the SDK (uses environment variables by default)
        cogbox = Cogbox()

        # Create a new sandbox
        sandbox = cogbox.create()

        # Execute a command
        response = sandbox.process.exec("echo 'Hello, World!'")
        print(response.result)

    if __name__ == "__main__":
        main()
    ```
  </TabItem>

  <TabItem label="Async" icon="seti:python">
    ```python
    import asyncio
    from cogbox import AsyncCogbox

    async def main():
        # Initialize the SDK (uses environment variables by default)
        async with AsyncCogbox() as cogbox:
            # Create a new sandbox
            sandbox = await cogbox.create()

            # Execute a command
            response = await sandbox.process.exec("echo 'Hello, World!'")
            print(response.result)

    if __name__ == "__main__":
        asyncio.run(main())
    ```
  </TabItem>
</Tabs>

## Configuration

The Cogbox SDK can be configured using environment variables or by passing options to the constructor:

<Tabs>
  <TabItem label="Sync" icon="seti:python">
    ```python
    from cogbox import Cogbox, CogboxConfig

    # Using environment variables (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
    cogbox = Cogbox()

    # Using explicit configuration
    config = CogboxConfig(
        api_key="YOUR_API_KEY",
        api_url="https://cogbox.pazity.com/api",
        target="us"
    )
    cogbox = Cogbox(config)
    ```
  </TabItem>

  <TabItem label="Async" icon="seti:python">
    ```python
    import asyncio
    from cogbox import AsyncCogbox, CogboxConfig

    async def main():
        try:
            # Using environment variables (COGBOX_API_KEY, COGBOX_API_URL, COGBOX_TARGET)
            cogbox = AsyncCogbox()
            # Your async code here
            pass
        finally:
            await cogbox.close()

        # Using explicit configuration
        config = CogboxConfig(
            api_key="YOUR_API_KEY",
            api_url="https://cogbox.pazity.com/api",
            target="us"
        )
        async with AsyncCogbox(config) as cogbox:
            # Your code here
            pass

    if __name__ == "__main__":
        asyncio.run(main())
    ```
  </TabItem>
</Tabs>

For more information on configuring the Cogbox SDK, see [configuration](/docs/en/configuration).
