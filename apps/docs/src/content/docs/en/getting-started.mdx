This section introduces core concepts, common workflows, and next steps for using Cogbox.

## Dashboard

[Cogbox Dashboard ↗](https://cogbox.pazity.com/) is a visual user interface where you can manage sandboxes, access API keys, view usage, and more.
It serves as the primary point of control for managing your Cogbox resources.

## SDKs

Cogbox provides [Python](/docs/en/python-sdk), [TypeScript](/docs/en/typescript-sdk), [Ruby](/docs/en/ruby-sdk), [Go](/docs/en/go-sdk), and [Java](/docs/en/java-sdk) SDKs to programmatically interact with sandboxes. They support sandbox lifecycle management, code execution, resource access, and more.

## CLI

Cogbox provides command-line access to core features for interacting with Cogbox Sandboxes, including managing their lifecycle, snapshots, and more. To interact with Cogbox Sandboxes from the command line, install the Cogbox CLI:

<Tabs syncKey="language">
<TabItem label="Mac">

Download the latest binary from GitHub releases and install it to `/usr/local/bin`.

For Apple Silicon (`arm64`):

  ```bash
  sudo curl -fL https://github.com/cognifyi/cogbox/releases/latest/download/cogbox-darwin-arm64 -o /usr/local/bin/cogbox && sudo chmod +x /usr/local/bin/cogbox
  ```

For Intel (`amd64`):

  ```bash
  sudo curl -fL https://github.com/cognifyi/cogbox/releases/latest/download/cogbox-darwin-amd64 -o /usr/local/bin/cogbox && sudo chmod +x /usr/local/bin/cogbox
  ```

</TabItem>
<TabItem label="Linux">

Choose the command for your Linux architecture. Both commands download the latest binary from GitHub releases and install it to `/usr/local/bin`, overwriting any existing version.

For `amd64` (`x86_64`):

  ```bash
  sudo curl -fL https://github.com/cognifyi/cogbox/releases/latest/download/cogbox-linux-amd64 -o /usr/local/bin/cogbox && sudo chmod +x /usr/local/bin/cogbox
  ```

For `arm64` (`aarch64`):

  ```bash
  sudo curl -fL https://github.com/cognifyi/cogbox/releases/latest/download/cogbox-linux-arm64 -o /usr/local/bin/cogbox && sudo chmod +x /usr/local/bin/cogbox
  ```

</TabItem>
<TabItem label="Windows">

```bash
powershell -Command "Invoke-WebRequest -Uri https://github.com/cognifyi/cogbox/releases/latest/download/cogbox-windows-amd64.exe -OutFile cogbox.exe"
```

</TabItem>
</Tabs>

After installing the Cogbox CLI, use the `cogbox` command to interact with Cogbox sandboxes from the command line.

To view all available commands and flags, see the [CLI reference](/docs/en/tools/cli).

## API

Cogbox provides a RESTful API for interacting with Cogbox Sandboxes, including managing their lifecycle, snapshots, and more. 
It serves as a flexible and powerful way to interact with Cogbox from your own applications.

To interact with Cogbox Sandboxes from the API, see the [API reference](/docs/en/tools/api).

## MCP server

Cogbox provides a Model Context Protocol (MCP) server that enables AI agents to interact with Cogbox Sandboxes programmatically. The MCP server integrates with popular AI agents including Claude, Cursor, and Windsurf.

To set up the MCP server with your AI agent:

```bash
cogbox mcp init [claude/cursor/windsurf]
```

For more information, see the [MCP server documentation](/docs/en/mcp).

## Multiple runtime support

The [TypeScript SDK](/docs/en/typescript-sdk) ships as a dual ESM/CJS package and works out of the box in **Node.js**, **Bun**, **Next.js**, **Nuxt.js**, **Remix**, **Vite SSR**, **AWS Lambda**, and **Azure Functions** without any extra configuration.

For **Cloudflare Workers**, set the Node.js compatibility flag in your `wrangler.toml`:

```toml
compatibility_flags = ["nodejs_compat"]
```

For **Deno**, install with `deno add npm:@cogbox/sdk` or import directly with the `npm:` specifier:

```typescript
import { Cogbox, Image } from 'npm:@cogbox/sdk'
```

For **browser apps with Vite** (or any browser bundler), install [`vite-plugin-node-polyfills`](https://www.npmjs.com/package/vite-plugin-node-polyfills) and add it to your `vite.config.ts`:

```typescript
import { defineConfig } from 'vite'
import { nodePolyfills } from 'vite-plugin-node-polyfills'

export default defineConfig({
  plugins: [nodePolyfills({ globals: { Buffer: true, process: true, global: true } })],
})
```

The SDK uses Node's `Buffer` for binary data (downloaded files, multipart bodies). Browsers don't ship `Buffer`, so the polyfill provides it. Without it, basic operations like `Image.base()` and `cogbox.list()` still work, but methods that handle binary payloads (`fs.downloadFile`, `fs.downloadFiles`) will throw.

Some runtimes don't expose the full set of Node.js APIs (browsers and edge runtimes have no filesystem, no `crypto`, etc.). Methods that depend on those APIs throw a clear runtime error instead of silently producing wrong results.

### Create a sandbox

Create a [sandbox](/docs/en/sandboxes) with default settings.

</TabItem>

```go
package main

    "context"
    "fmt"
    "log"

    client, err := cogbox.NewClient()

        log.Fatal(err)
    }

    sandbox, err := client.Create(context.Background(), nil)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Sandbox ID: %s\n", sandbox.ID)
}
```

### Create and run code in a sandbox

Create a [sandbox](/docs/en/sandboxes) and run code securely in it.

<Tabs syncKey="language">
<TabItem label="Python" icon="seti:python">

```python
from cogbox import Cogbox

cogbox = Cogbox()
sandbox = cogbox.create()

print(response.result)
sandbox.delete()
```

</TabItem>

```typescript

await sandbox.delete();
```

</TabItem>
<TabItem label="Go" icon="seti:go">

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/cognifyi/cogbox/libs/sdk-go/pkg/cogbox"
)

func main() {
    client, err := cogbox.NewClient()
    if err != nil {
        log.Fatal(err)
    }

    sandbox, err := client.Create(context.Background(), nil)
    if err != nil {
        log.Fatal(err)
    }

    response, err := sandbox.Process.ExecuteCommand(context.Background(), "echo 'Hello, World!'")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(response.Result)
    sandbox.Delete(context.Background())
}
```

```go
package main

import (
    "context"
    "log"

    "github.com/cognifyi/cogbox/libs/sdk-go/pkg/cogbox"
    "github.com/cognifyi/cogbox/libs/sdk-go/pkg/types"
)

func main() {
    client, err := cogbox.NewClient()
    if err != nil {
        log.Fatal(err)
    }

    volume, err := client.Volume.Get(context.Background(), "my-volume")
    if err != nil {
        volume, err = client.Volume.Create(context.Background(), "my-volume")
        if err != nil {
            log.Fatal(err)
        }
    }

    sandbox, err := client.Create(context.Background(), types.SnapshotParams{
        SandboxBaseParams: types.SandboxBaseParams{
            Volumes: []types.VolumeMount{{
                VolumeID:  volume.ID,
                MountPath: "/home/cogbox/data",
            }},
        },
    })
    if err != nil {
        log.Fatal(err)
    }
}
```

```java
import io.cogbox.sdk.Cogbox;
import io.cogbox.sdk.Sandbox;
import io.cogbox.sdk.exception.CogboxNotFoundException;
import io.cogbox.sdk.model.CreateSandboxFromSnapshotParams;
import io.cogbox.sdk.model.Volume;
import io.cogbox.sdk.model.VolumeMount;

import java.util.Collections;

public class App {
    public static void main(String[] args) {
        try (Cogbox cogbox = new Cogbox()) {
            Volume volume;
            try {
                volume = cogbox.volume().getByName("my-volume");
            } catch (CogboxNotFoundException e) {
                volume = cogbox.volume().create("my-volume");
            }

            VolumeMount mount = new VolumeMount();
            mount.setVolumeId(volume.getId());
            mount.setMountPath("/home/cogbox/data");

            CreateSandboxFromSnapshotParams params = new CreateSandboxFromSnapshotParams();
            params.setVolumes(Collections.singletonList(mount));

            Sandbox sandbox = cogbox.create(params);
        }
    }
}
```

### Create a sandbox with a Git repository cloned

Create a sandbox with a [Git repository](/docs/en/typescript-sdk/git) cloned to manage version control.

<Tabs syncKey="language">
<TabItem label="Python" icon="seti:python">

```python
from cogbox import Cogbox

cogbox = Cogbox()
sandbox = cogbox.create()

sandbox.git.clone("https://github.com/cognifyi/cogbox.git", "/home/cogbox/cogbox")
status = sandbox.git.status("/home/cogbox/cogbox")
print(f"Branch: {status.current_branch}")
```

<TabItem label="Go" icon="seti:go">

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/cognifyi/cogbox/libs/sdk-go/pkg/cogbox"
)

func main() {
    client, err := cogbox.NewClient()
    if err != nil {
        log.Fatal(err)
    }

    sandbox, err := client.Create(context.Background(), nil)
    if err != nil {
        log.Fatal(err)
    }

    sandbox.Git.Clone(context.Background(), "https://github.com/cognifyi/cogbox.git", "/home/cogbox/cogbox")
    status, err := sandbox.Git.Status(context.Background(), "/home/cogbox/cogbox")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Printf("Branch: %s\n", status.CurrentBranch)
}
```

```java
import io.cogbox.sdk.Cogbox;
import io.cogbox.sdk.Sandbox;
import io.cogbox.sdk.model.GitStatus;

public class App {
    public static void main(String[] args) {
        try (Cogbox cogbox = new Cogbox()) {
            Sandbox sandbox = cogbox.create();
            sandbox.git.clone("https://github.com/cognifyi/cogbox.git", "/home/cogbox/cogbox");
            GitStatus status = sandbox.git.status("/home/cogbox/cogbox");
            System.out.println("Branch: " + status.getCurrentBranch());
        }
    }
}
```

```bash
# Create a sandbox
curl 'https://cogbox.pazity.com/api/sandbox' \
  --request POST \
  --header 'Authorization: Bearer <API_KEY>' \
  --header 'Content-Type: application/json' \
  --data '{}'

# Clone a Git repository in the sandbox
curl 'https://proxy.cogbox.pazity.com/toolbox/{sandboxId}/git/clone' \
  --request POST \
  --header 'Authorization: Bearer <API_KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
  "url": "https://github.com/cognifyi/cogbox.git",
  "path": "/home/cogbox/cogbox"
}'

# Get repository status
curl 'https://proxy.cogbox.pazity.com/toolbox/{sandboxId}/git/status?path=/home/cogbox/cogbox' \
  --header 'Authorization: Bearer <API_KEY>'
```
